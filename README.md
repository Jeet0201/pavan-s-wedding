# Garba Glow Wedding Invite

Build a premium, mobile-first digital wedding invitation website. The design should be luxurious and elegant, featuring traditional Gujarati floral motifs, with a light cream and gold color palette. Include smooth fade-in animations on scroll.

Please include the following sections in order:

Hero Section: A 'Tap to Open' interactive button or animated envelope that reveals the main invitation.

Couple Section: Elegant serif typography for the couple's names, a warm welcoming message, and a beautiful arch-shaped image placeholder for the couple's photo.

The Date & Countdown: Display the dates 'December 1 - 3, 2026' prominently, followed by a live countdown timer showing Days, Hours, Minutes, and Seconds.

Event Itinerary: A vertical timeline for the events. Include sample events like Mandap Muhurat, Garba Night, and the Main Wedding Ceremony with times.

Venue Info: A beautiful card displaying the venue as 'Matrushree Party Plot, Latuda, Surendranagar'. Add a button that says 'View on Google Maps'.

Dress Code: A section mentioning festive traditional wear, along with a small aesthetic color palette display (4 color circles).

Footer: A warm closing message saying 'We can't wait to celebrate this special beginning with you.'
